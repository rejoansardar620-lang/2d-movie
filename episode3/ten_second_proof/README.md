# 10-second animated family pilot — motion first

This is a **separate 10-second test**, not another two-minute render. It uses
the first ten seconds of the previously mastered dialogue, with Rahul, Priya,
Aarav and Anaya in the garden. The purpose is to test whether this art/animation
method is worth expanding into additional ten-second shots **after feedback**.

## The 10-second sequence

| Time | Movie action |
|---|---|
| 0.0–1.24 | Wide garden entrance: Rahul walks in; Aarav runs past his family. Different foot/knee and hand/elbow motions are keyed to distinct gait tempos. The run ends at the next camera cut. |
| 1.24–3.58 | Cut closer to Rahul's greeting. He changes to a purposeful open-palm speaking pose; audio-driven mouth motion, eyes and brows. |
| 3.58–4.38 | Wide view: Priya finishes her separate walk-in, Anaya watches. |
| 4.38–7.35 | Priya's closer conversational shot; her raised hand, eyebrow movement and audio-timed mouth. |
| 7.35–8.00 | Brief family reaction bridge. |
| 8.00–9.50 | Aarav's playful 'snacks?' punchline in a closer conversational shot. |
| 9.50–10.00 | Return to the whole family for a reaction and gesture reset without visible pose popping. |

## Technical approach: open-source, no proprietary animation plugins

### Reference matching: the proven two-minute girl animation

We inspected `Everyday_English_2_Minute_Preview (2).mp4` in the connected
repository and its editable source
`Everyday_English_Project/action_render.py`. That movie uses an articulated
body puppet and its `face(shape, blink)` function **redraws a separate mouth
for each Rhubarb viseme, with eyelid-covered blinks**. That is the quality
reference for this *ten-second-only* test; this film now employs the same
explicit facial-layer principle. It does **not** claim that the mesh body
has already been converted to the full reference IK puppet.

- Original painted art sheets remain source of character identity; they are **not rendered as a static frame with horizontal sliding only**.
- OpenCV inverse mesh displacement animates **separate locations** for hands, elbows, knees, ankles, neck, brow and precisely located eyes without detaching heads from necks. Each actor has *different* movement timing and gaze.
- **Face fix:** `face_rig.py` has independently measured eye/mouth anchors for all four characters' `talk`, `idle`, and `walk` images. Previous nominal landmarks missed their eyes and mouths; those incorrect controls have been removed.
- The existing eye illustrations are preserved, with calibrated eye tracking, natural saccades, and independent eye-closing eyelid overlays. Distinct, **actual drawn mouth shapes** now change on Rhubarb cues, rather than deforming empty cheek pixels.
- Purpose-illustrated **walk, idle and speaking** poses provide the core physical silhouettes. Independently deformable fields add body-part motion and breathing between drawings.
- Rhubarb's original open-source dialogue alignment (`episode3/audio/rhubarb_cues.json`) controls viseme states. The four-voice narration is sourced from the original editable FLAC audio; the foley is regenerated by the original source script.
- Includes deliberate film cuts between full-body action and closer conversational performances, plus contact shadows and unobtrusive subtitles.
- Entire pilot is **240 frames, 24 fps, exactly 10.000 sec, 1920×1080 H.264/AAC**.

## Rebuild

From the **complete** 2d-movie project (the source ZIP accompanying the prior film):

```bash
python3 -m pip install numpy pillow opencv-python-headless
python3 episode3/ten_second_proof/render.py --preview
python3 episode3/ten_second_proof/render.py
python3 -m unittest discover -s episode3/ten_second_proof -p 'test_*.py' -v
```

The full source tree must include `episode3/assets_premium/actors`, the existing
`episode3/audio/narration_master.flac`, and painted background assets. The
renderer takes **no video frames from any earlier film**. The foley synthesis
is entirely reproducible from `episode3/premium_foley.py`.

Output files:

- `output/Ten_Second_Animated_Family_Pilot.mp4` — 10-second edited clip.
- `output/ten_second_contact_sheet.jpg` — 14 opening, acting and reaction checks.
- `render.py` — editable directing, movement and deformation source.
- `face_rig.py` — editable, per-pose calibrated eye/eyelid and mouth controls.
- `test_pilot.py` — objective media, facial and body-mesh checks.

## Critical honest limitations

This **is not yet a complete production-grade 2D skeletal rig**. The lip
shapes, gaze and blink controls now work on the correct face coordinates, and
the limb fields move independently. But this is still a limited-keyframe
*mesh-deformation body pilot*. Accurate independent finger articulation, full
profile turnarounds, and planted-foot locomotion with inverse kinematics
remain to be developed before claiming studio-level natural animation.

This release asks for approval of a **10-second direction only**. Do not start
another ten-second segment or a two-minute film without review of the motion.
